# Short-Term Price Prediction for Equinor and Aker BP

**Course:** MEPA2315 Introduction to Artificial Intelligence, NTNU Ålesund, autumn 2026

## Description

Group project (three students) on short-term price prediction with horizons of h = 3–10 trading days for Equinor (EQNR) and Aker BP (AKRBP). Predictions are based on market and sector data: OSEBX, the Oslo Børs energy index, other sector indices, Brent crude and USD/NOK.

## Folder overview

| Folder / file | Purpose |
|---|---|
| `data/raw/` | Untouched source files, one CSV per series (not tracked by git) |
| `data/processed/` | Cleaned data and features (not tracked by git) |
| `src/` | Source code |
| `notebooks/` | Exploratory notebooks |
| `reports/` | Assignment 1, literature review, final report |
| `SOURCES.md` | Data source log (origin, retrieval date, price adjustment) |
| `requirements.txt` | Python dependencies (added once the group decides) |
